# 🚀 Backend Flask + MySQL

API REST em Python para cadastro e consulta de usuários integrada com banco de dados MySQL.

## 📌 Rotas da API

- `POST /usuarios`: Cadastra um usuário (`nome`, `email`).
- `GET /usuarios`: Retorna a lista de usuários cadastrados.

## 🛠️ Tecnologias

- Python 3
- Flask
- MySQL + `mysql-connector-python`
